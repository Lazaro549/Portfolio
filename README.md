# Lázaro Gómez Vitolo Portfolio

Live site: https://lazaro549.github.io/Portfolio/

A personal portfolio website for Lázaro Gómez Vitolo, focused on AI, robotics, and developer tooling. The site presents a professional profile, highlights technical strengths, demonstrates evidence of impact, and links to downloadable career materials.

## Overview

This project is a single-page portfolio built with plain HTML and CSS. It is designed to feel modern, technical, and product-focused, with a dark green visual theme and a strong emphasis on AI and robotics work.

The page includes:

- A hero section introducing the profile and specialization
- A skills/stack overview across AI, robotics, and tooling
- Case-study style project highlights with technical details
- Evidence cards summarizing outcomes and metrics
- Social links and contact call-to-actions
- Download links for CV and cover letter

## Run Locally

Because this is a static site, you can preview it by opening `index.html` directly in a browser.

For a local server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
